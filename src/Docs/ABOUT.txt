    FurryArtStudio is a lightweight yet powerful local tool designed specifically for organizing and managing fursona artworks, reference materials, OC content, and image documents.

    Core Advantages
    - Completely Free: FurryArtStudio is committed to staying fully free with all updates.
    - Offline Operation: All data is stored exclusively on your local device.
    - Privacy First: Apart from checking for updates, the program never connects to the internet, nor does it upload any user data or artwork information.
    - Open Source License: Apache License 2.0 (see LICENSE.txt)
    - Current Platform: Windows (more platforms are planned for the future)
